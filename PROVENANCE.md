# Provenance

Catalog Ingestion Lab is an independent, synthetic portfolio/reference project created in 2026.

- The product-catalog domain, API contract, schemas, examples, tests, and documentation were created specifically for this repository.
- No employer source code, proprietary algorithms, internal architecture, private documentation, credentials, customer information, or production data were used.
- Sample SKUs, names, prices, and inventory values are fictional.
- The implementation uses publicly documented .NET, ASP.NET Core, SQLite, CsvHelper, and xUnit APIs through their published NuGet packages.
- AI-assisted drafting and review were used during development. The repository owner is publishing the project and remains responsible for the code they maintain.

Third-party packages retain their own licenses. NuGet metadata and the generated dependency graph are the source of truth for those components; the repository's MIT license applies only to original project material.
